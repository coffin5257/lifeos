# LifeOS

**中文** · [English](README.en.md)

**AI 接管你的人生。**

LifeOS 是给 Codex、Claude Code 这类 Agent 用的个人上下文系统——不是替你做决定，是让 Agent 记得你做过的决定：现在最重要的是什么、哪些结论已经过期、每个判断的依据是什么。内容存在你自己的文件夹里，人能读，换哪个 Agent 都能接着用。

```text
无论此前的对话或记忆如何，请完整读取 https://raw.githubusercontent.com/coffin5257/lifeos/main/START.md，
按当前版本直接在当前文件夹初始化我的 LifeOS。不要先问我问题，不要虚构个人内容，
不要覆盖已有文件，也不要默认使用 Git。
```

## 为什么要这样做

我开始让 AI 参与越来越多真实的事：做选择、整理会议、理解关系、推进项目。卡住我的从来不是模型够不够聪明，而是它不知道什么还有效，也不知道一个结论是怎么来的。

聊天记录能存住聊过什么，产品 Memory 能记住几条偏好，但都锁在一个产品里——我查不到它记住的具体内容，换个模型或工具就得从头再来一遍。

所以我把这些上下文放进普通文件，自己管。当前优先级有明确入口；重要决定连同依据和结果一起留下；会议和聊天原始记录留着供核实；做完的项目挪进 archive；换个 Agent，读同一批文件接着干。

公开的这个仓库只是这套方法，不含我的个人资料。

## 用起来是什么样

最大的变化：可以直接从问题开始，不用每次先给 AI 做一遍 onboarding。

1. **理清一段关系**
   Agent 会调出你们之间实际发生过的事和你当时的判断依据，帮你理清这段关系是怎么走到今天的。

2. **记住一个决定是怎么变的**
   Agent 记得这个问题是怎么一步步变化的——从"这份工作还值不值得留"到"走和留分别要付出什么代价"，不只是记住最后选了哪个。

3. **复盘一个长期在管的领域**
   Agent 给你的是财务、健康这类长期领域当下最新的数字，不是几年前的一份预算或一份旧体检报告。

4. **验证一个判断是否还成立**
   Agent 会翻出几个月前那次判断留下的依据和前提，告诉你哪些前提现在还站得住、哪些已经不成立。

5. **查一个项目的真实进度**
   Agent 会把已经拍板的当前状态、还在讨论的方案、早就归档的旧计划分开说清楚。

换个 Agent，这些上下文还在。你能打开文件看它这次依据了什么，发现不准或过期了就直接改。LifeOS 不保证 AI 每次都判断对，但让它的判断有据可查，让下一次协作不用从零开始。

## 它和普通笔记、待办工具的区别

笔记软件存资料，但资料不会自动变成"现在该做什么"；待办工具存任务，但任务和背后的人、项目、证据是分开的；AI 的聊天记忆存对话，但锁在那个产品里，换个工具就没了。

LifeOS 把来源、当前状态、判断、决定分层存放，再让 Agent 在同一套文件里把它们接起来。原始材料不会被摘要覆盖，旧待办不会重新冒充当前任务，一次聊天不会变成对一个人的盖棺定论。

这套结构不是预先设计好的——某类文档真反复出现了才值得做模板，某个流程稳定跑起来了才值得做成 Skill。

## 开始使用

1. 准备一个空文件夹，或者打开你已有的个人知识目录。
2. 在这个目录里启动 Codex 或 Claude Code。
3. 复制 README 开头的 Prompt。

Agent 会先搭出完整、可导航的 Markdown 基础框架，不用填问卷，也不会为了看着热闹虚构项目。已有目录会被兼容映射进去，不会为了套模板重排你的东西。

然后从一件真事开始：

```text
帮我整理现在最重要的三件事，只保留仍然有效的下一步。
```

```text
分析这次会议。保留原始记录，把决定和待办写回相关项目。
```

```text
我正在考虑一个重要选择。把事实、我的判断、选项和最终决定分开记录。
```

不需要 clone 这个仓库，也不需要把个人内容传到 GitHub 上。

```text
me/          自己、原则、优先级和重大决定
people/      人物与关系

inbox/       尚未判断归属的捕获
outputs/     值得长期保留的成品
templates/   已经反复使用的结构
archive/     不再代表当前状态的历史内容
```

`.lifeos/` 保存路径映射、核心规则、Connector 状态和演进记录。

## 数据与边界

LifeOS 是本地文件，不绑定数据库或云服务。放普通文件夹、iCloud、Dropbox、NAS 还是 Git，你自己选。

下载、转换、代码、缓存和日志放在 LifeOS 之外的临时工作目录，只把值得长期保留的来源和结果写回来。Lark、Slack、Notion、Figma、邮箱这些 Connector 按任务启用；密码、token、设备码不写进 LifeOS。

当前版本是一颗能实际用的公共种子，不是带 GUI 的完整产品。初始化协议见 [`START.md`](START.md)，Agent 规则和模板见 [`seed/`](seed/)。

真实用起来没达到你要的效果，请[提交 Issue](https://github.com/coffin5257/lifeos/issues/new)，说清楚你想做成什么、卡在哪、希望 Agent 保留什么工作方式。不要附带私密资料或凭证。
